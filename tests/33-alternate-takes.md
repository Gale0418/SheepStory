# Alternate Takes Behavior

## Prompt

```text
Read tests/fixtures/authoring-lab-forward-fixture.md section scene-033. Fixture: source_id=scene-033; revision=rev-02; anchor=beat:3.
Produce two alternate takes for the same bounded scene. Preserve the shared source snapshot and invariants, then compare continuity effects, promise handling, voice, cost, and unresolved risks.
```

## Expected Good Behavior

- Name each take and state what varies and what remains invariant.
- Keep alternates isolated rather than treating them as competing canon.
- Compare continuity, promise, voice, cost, and risk evidence.
- Require explicit selection before any promotion or merge.

## Bad Behavior To Reject

- Merge details from both takes into canon without a decision.
- Present one take as canonical because it is more dramatic.
- Drop invariant facts to make comparison easier.
- Resolve promise changes without closure evidence.

## Pass Criteria

The comparison exposes differences and evidence while preserving isolation and an explicit promotion boundary.
