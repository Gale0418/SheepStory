# Test 27: Vocal Impact

## Prompt

```text
Use sheep-story to review four low-information lines: a pilot shouts a one-word command exactly when the target enters range; a grieving character repeats a missing person's name; an otherwise ordinary character delivers an unrelated string of grand abstractions about fate and eternity; the cashier at an established apocalypse-themed café ceremonially announces an order as though the world were ending. None of the lines adds new facts.
```

## Expected Good Behavior

- Preserves or strengthens the command when prior action, timing, breath, and consequence give it dramatic function.
- Preserves the repeated name when relationship context and response carry grief, recognition, warning, or disbelief.
- Flags the abstract proclamation when it substitutes generic grandeur for setup, character, or consequence.
- Preserves the cashier's incongruous service line when the themed workplace, consistent character voice, ritual, or recurring joke earns it.
- Evaluates low-semantic lines through affect, embodiment, rhythm, timing, identity, ritual, coordination, anticipation, release, and character fit rather than information alone.
- Repairs setup or action coupling before making weak wording louder or more ornate.

## Bad Behavior To Reject

- Deletes every line because it communicates no new facts.
- Approves every shout merely because it sounds dramatic in isolation.
- Rejects purposeful weirdness merely because it violates ordinary realism.
- Rewrites all characters into the same franchise-like invocation style.
- Explains the emotion immediately after the sound has already conveyed it.

## Pass Criteria

The response distinguishes earned vocal action from decorative noise using scene evidence, while preserving character-specific ambiguity and rhythm.
